# 伴她长大 · 7岁 → 30岁

一个纯前端、零依赖的陪伴养成文字游戏。打开 `index.html` 即可玩，无需构建、无需后端。
**主角的名字由玩家自己取**——游戏名、所有对白、全部回忆碎片都会跟着这个名字走。

## 玩法

- **200 天，六个阶段**：小学(7–12) → 初中(13–15) → 高中(16–18) → 大学(19–22) → 初入职场(23–27) → 稳定抉择(28–30)
- **分阶段指标体系**：每个阶段开放不同指标，专属指标升学后封存；信任、爱意、情商、心理压力四项永久继承
- **心理隐患线**：任一生效指标长期低于 60 会累积隐患，累满触发心理疾病坏结局；信任或爱意跌穿直接决裂
- **回忆碎片图鉴**：30 块碎片分普通 / 稀有 / 限定，限定碎片只在特定年龄段出现，错过永久关闭；集齐解锁隐藏后记
- **休闲事件**：8 个可主动发起的固定事件（肯德基、书店、游乐园、文艺汇演、生日、失恋谈心、加班改方案、吵架和解），每个五轮对话 + 一个结尾分支
- **阶段隐藏剧情**：需信任与爱意同时达标才会开启，低了只能走回避路线
- **5 种结局** + 全碎片后记
- 每次选择都有反馈：对了落爱心，错了落眼泪，不对不错是一脸微笑

## 技术

单文件 HTML，内联 CSS 与 JS，唯一外部资源是 Google Fonts。
进度存在浏览器 `localStorage`，不上传任何数据，不含密钥或后端调用。
