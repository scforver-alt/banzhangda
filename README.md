# 伴她长大 · 7岁 → 30岁

一个纯前端、零依赖的陪伴养成文字游戏。打开 `index.html` 即可玩，无需构建、无需后端。
**主角的名字由玩家自己取**——游戏名、所有对白、全部回忆碎片都会跟着这个名字走。

## 玩法

- **带界面的养成游戏**：顶部状态栏（天数/年龄/阶段/季节日期/零花钱/心情）、左侧人物卡、中间剧情舞台、右侧属性进度条、底部八键菜单
- **每天三个时段**（上午/下午/晚上）自由安排：学习 / 休息 / 社交 / 才艺 / 打工，约 70 种活动，每张卡标注影响的指标和她的喜欢度星级
- **外出探索**：六阶段各 6 个地点，带剧情标记的地点进入五轮连续对话，其余触发随机偶遇
- **商店与送礼**：零花钱系统，22 件商品 + 4 种节日限定礼盒。投其所好大幅加分，送习题册她会沉默三秒
- **爱好 L1–L5**：反复安排同类才艺积累经验，L4 起触发高光剧情
- **聊天陪伴**：6 组话题，每组多轮对话
- **纪念日**：生日、儿童节、毕业季、跨年，共 13 次，限定礼盒与稀有碎片
- **六阶段独立指标**：专属指标升学后封存，信任/爱意/情商/心理压力永久继承
- **心理隐患线**：任一指标长期低于 60 累积隐患；信任或爱意跌穿直接决裂
- **31 块回忆碎片**，限定碎片过期永久关闭，集齐解锁隐藏后记
- **S / A / B / C / D / E 六档结局**，结算页给出人生关键词、最高最低属性、爱好与碎片进度

## 技术

单文件 HTML，内联 CSS 与 JS，唯一外部资源是 Google Fonts。
进度存在浏览器 `localStorage`，不上传任何数据，不含密钥或后端调用。
